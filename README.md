# 指バリア

下落が来たら、チャートを指で左右にこすってバリアを張る。こすりが足りれば反発、足りなければ強制ロスカット。何回耐えられるか。

遊ぶ：https://nasubi-no-oniwa.github.io/yubi-barrier/

- `index.html` … ゲーム本体（1つのファイル）
- `database.rules.yubi.json` … ランキングのルール。GitHub に上げると自動で ft-green の `yubi` に反映（ほかのゲームのルールはそのまま）
- `test/rules-test.mjs` … ルールの試験（GitHub の上で試し用のデータベースを立てて試す）

## しくみ
- はじめに MV（棒人間がパソコンの前に座り、画面に寄っていく）。右上のスキップで飛ばせる
- k回目（0から）の下落：ふつうに落ちきるまで `max(1.5, 3.6−0.12k)` 秒。止めるのに必要なこする量は `3.0+0.4k`（横に動かした長さ ÷ 画面の短い辺×0.95）。こするほど下落がゆっくりになる
- 必要な量に届けば反発して +1、ロスカットの線まで落ちたら終わり
- ランキングは名前なし。1人1つ（いちばん多い回数）で、回数ごとの人数を出す。今日と全期間
- はじめた瞬間にサーバーの時刻を `yubi/runs/人` に書く。記録は「回数×1.5秒−3秒」より早くは載らない
- 隠し：下の「ポジション」の帯を横にずらすと「損切りする」が出る。押すと称号「損切りできる人」。損切りした人は回数の人数には入れず、`yubi/cut` に1人1つで数えてランキングの一番上に出す
- 消したい記録は、Firebase の `yubi/hidden/人のID` に `true` を入れると出なくなる
